# Algoritmos em C

Repositório dedicado aos exercícios e atividades de programação desenvolvidos em linguagem C durante meus estudos.

## Estrutura do repositório

### Exercícios antigos (2023)

Exercícios desenvolvidos em 2023, abordando conceitos fundamentais de programação, como variáveis, operadores aritméticos, estruturas condicionais e entrada e saída de dados.

| Arquivo | Descrição |
|---|---|
| `calculo_calorias_refeicao.c` | Calcula as calorias totais de uma refeição. |
| `calculo_media_aluno.c` | Calcula médias e classifica o desempenho de um aluno. |
| `calculo_propriedades_solidos.c` | Calcula propriedades geométricas e estimativas de peso de sólidos. |
| `classificacao_cliente_bancario.c` | Classifica clientes bancários conforme o saldo. |
| `consumo_combustivel.c` | Calcula a quantidade e o custo estimado de combustível para uma viagem. |
| `consumo_tinta.c` | Calcula o consumo de tinta para pintar uma parede. |
| `notas_caixa_eletronico.c` | Calcula a distribuição de notas em um saque. |

## Objetivo

Organizar meus exercícios de programação, preservar meu histórico de aprendizado e acompanhar minha evolução no desenvolvimento de software.
